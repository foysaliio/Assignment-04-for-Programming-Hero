# Assignment 04

This assignment focuses on TypeScript problem solving, type safety, functions, interfaces, union types, arrays, objects, and real world logic.

## Problems

### 01 - Battery Level Status

Determines a phone's battery status based on its current percentage using conditional logic.

### 02 - Table Booking Confirmation

Generates a restaurant booking confirmation message using a properly typed booking object.

### 03 - Weekly Expense Tracker

Calculates the total weekly expenses from an array of numbers, including handling an empty array.

### 04 - Traffic Light Action

Determines the correct driving action based on a traffic light color using a TypeScript union type.

### 05 - Quiz Score Summary

Calculates the total and average score from an array of quiz scores and returns the result as a typed object.
